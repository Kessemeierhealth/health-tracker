# ❤️ HealthTracker

**HealthTracker** ist eine moderne, datenschutzorientierte Gesundheitsplattform für Einzelpersonen und Familien.

Die App unterstützt den Nutzer dabei, Gesundheitsdaten zu erfassen, Entwicklungen zu erkennen und den Alltag durch intelligente Automatisierung zu erleichtern.

---

# Ziele

HealthTracker soll

- möglichst viele Daten automatisch übernehmen
- unnötige Eingaben vermeiden
- Gesundheitsdaten verständlich darstellen
- Zusammenhänge erkennen
- Trends analysieren
- nachvollziehbare Empfehlungen geben
- mehrere Familienmitglieder verwalten
- Gesundheitsdaten sicher speichern

Die App ersetzt **keinen Arzt** und stellt **keine Diagnosen**.

# Datenschutz

HealthTracker verfolgt einen **Offline-First-Ansatz**.

Grundsätze:

- Daten gehören dem Nutzer.
- Lokale Speicherung.
- Verschlüsselung.
- Cloud nur auf Wunsch.
- Export jederzeit möglich.
